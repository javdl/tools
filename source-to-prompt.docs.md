Convert local code projects into structured LLM prompts entirely in your browser. Select a folder using the File System Access API, filter files by type or name patterns, optionally remove comments and minify code, then copy a formatted output with file tree and contents ready for pasting into Claude, ChatGPT, or other LLMs. All processing happens locally for privacy.
